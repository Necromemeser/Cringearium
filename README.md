# Cringearium

**Cringearium** — это веб-приложение образовательной платформы, предназначенное для подбора и оплаты образовательных курсов с возможностью персонализированной помощи от интеллектуального помощника.

## Функциональные возможности
Проект предоставляет следующие функциональные возможности:
- Каталог курсов с изображениями и описаниями;
- Поиск и фильтрация курсов по названию;
- Интеллектуальный помощник на базе искусственного интеллекта для помощи в обучении;
- Управление корзиной: добавление и удаление курсов, оформление заказов;
- Онлайн-оплата заказов через платёжную систему YooKassa;
- Личный кабинет пользователя с доступными курсами;
- Авторизация и аутентификация с разграничением прав доступа (пользователь / администратор);
- Панель администратора для управления пользователями и каталогом курсов;
- Адаптивный интерфейс, обеспечивающий корректное отображение на различных устройствах.

## Технологии

- **Backend:** Java, Spring Boot, Spring Security
- **Frontend:** HTML, CSS, JavaScript
- **База данных:** PostgreSQL
- **ИИ-интеграция:** WebClient + DeepSeek API
- **Платёжная интеграция:** YooKassa API
- **Сборка и управление зависимостями:** Maven
- **Контейнеризация:** Docker
- **Архитектура:** MVC + REST API
- **Веб-сервер:** Tomcat (встроенный в Spring Boot)
